# Personal Portfolio Website (Week 1 + Week 2 - HTML, CSS, JavaScript)

## Project Overview

This project is a personal portfolio website built using **HTML, CSS, and JavaScript**.
The goal of this project is to understand how to structure, style, and add interactivity to a modern web application.

The website includes multiple sections such as **Home, About, Skills, and Contact**, and demonstrates a clean, responsive, and user-friendly interface.

---

## Objectives

- Understand HTML structure and semantic elements
- Apply CSS for styling and layout design
- Implement responsive design using media queries
- Use Flexbox and Grid for layout management
- Add interactivity using JavaScript
- Build a professional-looking portfolio website

---

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Variables)
- JavaScript (Vanilla JS)
- Visual Studio Code
- Web Browser (Chrome / Edge / Firefox)

---

## Setup Instructions

1. Install **Visual Studio Code**.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Open `index.html`.
5. Run using Live Server or open in browser.
